Class ColorFieldControl

A draggable colour field. Paints a Robust.Client.UserInterface.Controls.ColorSelectorStyleBox and reports the pointer position as a normalised value on each axis.

Remarks

This exists because every slider the engine ships is one-dimensional, and a saturation/value square needs two axes at once. The gradient itself is not custom: ColorSelectorStyleBox is shader-backed and takes its axes as plain public fields, so a square is the same amount of setup as a strip.

Y is measured from the bottom, matching the direction the gradient is drawn.
