Class CmuChoiceCard

One bordered choice: a button that is a segment of the card, and a line or two saying what the choice actually does.

Remarks

Extracted from the join-round window because the same shape keeps coming up - a short list of terminal choices where the label alone does not explain the option. "Join Govfor" and "Admin Help" have the same problem: the button names the action and nothing tells a new player what it means. Anywhere that is true, this control fits.

The button is deliberately part of the box rather than something placed on it. It fills the card's height, runs flush into the border, and its only edge is the single rule facing the text - bordering all four sides would put a box inside a box, which this theme has refused everywhere else.

Colours are passed in rather than taken from CrtTerminalPalette. The palette is one hue by design, and the whole reason a caller reaches for this control is that its choices need telling apart - a faction, a severity, an audience. Terminal is there for callers that genuinely want the house style.
