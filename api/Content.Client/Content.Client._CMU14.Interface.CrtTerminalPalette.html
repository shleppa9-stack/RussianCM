Class CrtTerminalPalette

The surface ladder and text tones the CRT theme is built from - and the neutral ladder that stands in for it when the theme is switched off.

Remarks

The shipped palette derived all eighteen of its colours from one hue and packed every surface between #000906 and #032314 - about five percent of the luminance range, all of it near-black. Three problems followed from that one fact, and all three showed up in practice: surfaces could not be told apart by fill, so every boundary had to be a border, which is what produces the box-in-box look; nothing could signal danger, because a fill could only ever be the theme colour brighter; and a scanline had no luminance to modulate, so it was either invisible or a colour cast.

This ladder fixes the cause rather than the symptoms. Four surface steps, each visibly lighter than the last, so a panel can sit inside a panel and be read as separate without a rule between them. Text is genuinely bright - an Aliens terminal is high contrast, dim green on black is a different look entirely. Caution and alert are off-hue on purpose.

Every member is a property, not a field, and every one of them is mode-aware. That is the whole reason this file reads the way it does. These used to be plain constants, so a control wearing a Crt* style class kept its green fill after the theme was switched off - and since the XAML names those classes directly, that was most of the lobby. Turning the theme off left a green UI in a proportional font, which is nobody's design. StyleNano's own colours had always fallen back; this file was the one that did not.

The off values are the stock NanoUI greys, keyed to what each step is used *for* rather than to its green's luminance: the panel steps land on the existing neutral panel colours, and the interactive steps land on NanoUI's own button colours, so a button in base mode is the slate it always was.

Remarks

The same trick as ChatRowTint(Color, Single), aimed at text rather than fills: take the hue only, and rebuild it at a known luminance. Picking channel colours by eye is what produced the shipped set - LightSkyBlue, HotPink, MediumPurple - where the pink burns and the purple is nearly unreadable on a dark ground, because equal HSV value is nothing like equal brightness across hues.
