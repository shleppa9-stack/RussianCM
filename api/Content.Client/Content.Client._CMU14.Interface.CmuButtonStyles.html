Class CmuButtonStyles

The semantic button set: one padding and one height across all of them, differing only in fill and text tone.

Remarks

Written because the Observe window needed a coloured button and there was nowhere to get one. The stylesheet offers CrtButton and CrtAttentionButton - two steps of the same green - so anything that had to say "this one is dangerous" hand-rolled a at the call site. That is how the Observe window ended up with its own copy, and it is how the next window would have too.

It also fixes a real bug rather than only adding colour. CrtAttentionButton and a plain unstyled Robust.Client.UserInterface.Controls.Button carry different content margins, so a row mixing the two had one label sitting closer to its edge than its neighbours - which read as a clipped button. Every variant here uses the same margins, so a mixed row lines up.

Fills come from ChatRowTint(Color, Single), which pins a hue to Surface2's luminance rather than its HSV value. At equal value a red fill reads far heavier than a green one against a dark ground; pinning luminance is what lets a row of differently-coloured buttons weigh the same.
