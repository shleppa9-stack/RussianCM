Class NukeEntitiesCommand

Shared plumbing for the nuke:* cleanup commands in this file: [all] bool (default false, true = serious cleanup, drops the per-command safety filter) + prototype id filter args, batch deletion of collected loose entities, prototype id completion, and the report line.
